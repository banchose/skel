# Pi Configuration

- Pi supports user-level and project configuration
- User-level: lives in agent directory typically `~/.pi/agent`
- Project: `./.pi`

## User-level Configuration

- `<agent-dir>/settings.json`

## Project Configuration

- `.pi/settings.json` (Project takes precedence)
- `.pi/mcp.json`
- `.pi/SYSTEM.md`
- `.pi/APPEND_SYSTEM.md` (Project takes precedence)
- `.pi/extensions/`
- `.pi/skills/`
- `.pi/prompts/`
- `.pi/themes/`
